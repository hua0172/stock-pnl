# Return Rate excludes Dividend Income (reverses an earlier decision)

`returnRatePercent` is `(realizedPnlTwd + unrealizedPnlTwd) / (avgCostTwd × quantityHeld) × 100` — it deliberately does not use `totalPnlTwd`, even though `totalPnlTwd` already includes Dividend Income as a third addend (see `CONTEXT.md`'s Total P&L entry).

This reverses an earlier explicit decision, made when dividend tracking was first designed, that Return Rate *should* include dividends (on the reasoning that a dividend-paying stock's reported return should reflect the income actually received from holding it, not just its price movement — see the dividend-tracking feature's spec). That decision shipped and was live in this codebase for a period. It was reversed after actually seeing the Return Rate chart in use: dividend income folded into a percentage meant to answer "how did the stock itself perform" made a bond ETF or high-yield stock's return look inflated relative to its actual price movement, when the dividend income was already fully visible elsewhere (the "股息收入" overview card, the per-stock dividend column, and Total P&L itself). Folding it into Return Rate too was judged to be double-counting rather than useful.

A future reader who finds an old reference to "Return Rate includes dividends" (in an earlier commit, or in memory of an earlier conversation) should treat this file as the current, correct state — not the earlier decision. If dividend-adjusted return ever matters again, it should be a distinctly-named, separate figure (e.g. "含股息報酬率") rather than redefining Return Rate back to include it silently.

# Use weighted-average cost, not FIFO, as the cost-basis method

This system tracks holdings across both Taiwan and US markets and needs one consistent way to price a partial sell against multiple buys made at different prices. We chose **weighted-average cost** — every buy folds into a single running per-share average, and a sell consumes at that average — over FIFO (matching the earliest buy's price to a sell first). Weighted-average is the convention used by Taiwanese brokerage apps, which is the frame of reference this system's numbers are meant to match; FIFO is the more common US-tax convention and was explicitly rejected here. Switching methods later would require recalculating every historical Realized P&L figure, since the two methods diverge as soon as more than one buy exists for a symbol.
